# JTV | The Future Is Unwritten

A static, responsive concept site for **JTV**, a future-facing creative television network. The site launches with a network homepage, a public mission page, and two developing program pages:

- **Eat Shit, Darling!** — Alternative comedy at Ravenswood Academy.
- **Star Trek: Arjuna** — Unofficial speculative science-fiction fan concept.

## Preview locally

Open `index.html` in a browser. No framework, build step, or package installation is required. An internet connection is helpful for loading the Google Fonts (a system-font fallback is provided).

## Publish to GitHub Pages

1. Create a new GitHub repository, for example `jtv-network`. The repository name can differ.
2. Upload the **contents** of this folder to its default branch (typically `main`).
3. Open the repository's **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. GitHub will provide a public URL, usually `https://USERNAME.github.io/jtv-network/`.

All links are relative, so the site works at a repository subpath or a custom domain.

## Edit show pages one at a time

- `shows/eat-shit-darling/index.html`
- `shows/star-trek-arjuna/index.html`

`assets/styles.css` controls the look across the network. `assets/site.js` provides the mobile menu. The Ravenswood poster lives at `assets/images/eat-shit-darling-poster.jpg`.

## Important distinctions

This is a **concept network**, not a claim that television programs are produced or actively airing. The public site marks the schedule and programming as exploratory. “Star Trek” is used for an **unofficial fan concept** and is not affiliated with or endorsed by its rights holders.

The internal founding philosophy is provided as a **separate** file, `JTV-Founding-Creative-Brief.md` (outside this upload-ready site ZIP). Keep those notes separate if the repository is public: files in public GitHub repositories are publicly readable even if a website does not link to them.
